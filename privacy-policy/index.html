Política de Privacidad de Petal

Última actualización: 22 de marzo de 2026

Petal ("la aplicación") es una aplicación de asistente de voz manos libres para ciclistas. Esta política explica qué datos recogemos, cómo los usamos y cómo los protegemos.

1. Datos que recogemos

  • Voz / Audio: Grabamos tu voz únicamente mientras el servicio está activo, para procesarla con la API de Google Gemini y responder a tus comandos de voz. No almacenamos grabaciones de audio en nuestros servidores.
  • Ubicación: Accedemos a tu ubicación GPS (precisa y aproximada) para funciones de navegación y recomendaciones de lugares cercanos. No almacenamos tu historial de ubicación.
  • Contactos: Leemos tus contactos localmente en el dispositivo para permitirte hacer llamadas por voz. No enviamos tu lista de contactos a ningún servidor.
  • Estado del teléfono: Detectamos llamadas entrantes para ofrecerte la opción de contestar o rechazar por voz. No registramos registros de llamadas.

2. Cómo usamos los datos

Todos los datos se usan exclusivamente para proveer las funciones de la app en tiempo real:

  • El audio de voz se envía a la API de Google Gemini para interpretar comandos.
  • La ubicación se usa para navegación y búsqueda de lugares cercanos (Google Maps / Places).
  • Los contactos se usan localmente para marcación por voz.

No vendemos, alquilamos ni compartimos tus datos personales con terceros con fines comerciales.

3. Servicios de terceros

La app utiliza los siguientes servicios externos, sujetos a sus propias políticas de privacidad:

  • Google Gemini API – procesamiento de lenguaje natural
  • Google Maps / Places API – navegación y lugares
  • Google Play Services

4. Almacenamiento y seguridad

Petal no dispone de servidores propios de almacenamiento de datos de usuario. Los datos sensibles (claves API) se almacenan localmente en el dispositivo. La comunicación con APIs externas se realiza mediante conexiones cifradas (HTTPS).

5. Menores de edad

Petal está dirigida a ciclistas adultos y no está destinada a menores de 13 años. No recogemos intencionadamente datos de menores.

6. Tus derechos

Puedes revocar cualquier permiso en cualquier momento desde los ajustes de tu dispositivo Android. Desinstalar la app elimina todos los datos locales.
